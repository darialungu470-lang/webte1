O projekte

Webová stránka predstavuje môj osobný profil, informácie o mojom štúdiu, záujmoch a zručnostiach. Obsahuje životopis, rozvrh s informáciami o aktuálnom čase a priebehu semestra a interaktívne pracovné prostredie s informačnými prvkami. Stránka je vytvorená pomocou HTML, CSS a JavaScriptu s dôrazom na responzívny dizajn a interaktivitu.
